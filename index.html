How it works

Your answers become a seed

Your answers are processed in this browser to select an English adjective and noun, calculate a PIN, and create an initials avatar. Repeat the same answers to get the same result.

Does the PIN match?

Open source: build on this project

Brave Monkey is a static site hosted on GitHub Pages: no application server receives your answers; calculations run in your browser. This reduces server-side exposure, though your browser, host/CDN, and extensions can still process ordinary page and network metadata. The source is public to inspect, so the algorithm is not secret—and the alias/PIN are not secure credentials.
